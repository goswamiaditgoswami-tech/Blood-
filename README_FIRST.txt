BLOOD REPORT ANALYSIS SYSTEM - QUICK START

1. Extract this ZIP file to a normal folder on your Windows laptop.
2. Make sure Python 3 is installed. During installation, select "Add Python to PATH".
3. Double-click run_project.bat.
4. The launcher installs Flask if needed and starts the app.
5. Open http://127.0.0.1:5000 in your browser if it does not open automatically.
6. Register a new account, then log in.

IMPORTANT:
- Keep app.py, analysis.py, database.db, requirements.txt, and run_project.bat together.
- HTML pages must remain inside the templates folder.
- This is a student demonstration project, not a medical diagnosis system.
- Keep a backup of database.db if you need to preserve existing records.
